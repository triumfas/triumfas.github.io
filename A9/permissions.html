Permissions explained

A9 (package lt.tbu.a9) · Last updated: 2026-10-13

A9 asks only for permissions it needs for its features. It has no internet permission, so none of the data below can leave your device. See the Privacy Policy.

Always declared

QUERY_ALL_PACKAGES – see all installed apps

A9’s core and only purpose is device search: finding and launching any app installed on the device from a T9 keypad. The search needs the complete list of installed apps. Without this permission Android hides most apps from A9, and search would find only a small fraction of them (we tested this on a real device). The list is used only on the device to search and launch apps; it is never transmitted.

REQUEST_DELETE_PACKAGES – uninstall dialog

Used only when you choose Uninstall in an app’s long-press menu. Android then shows its own confirmation dialog; A9 never uninstalls anything without it.

RECEIVE_BOOT_COMPLETED – restore the Quick Launch notification

Used only to bring back the optional Quick Launch notification after the device restarts, if you enabled it.

Optional – only if you enable the feature

READ_CONTACTS – contact search

Used only if you turn on Contacts in settings, so you can search contacts by name or number, and call, message or open them. Contacts are used only in memory on the device and are not transmitted.

PACKAGE_USAGE_STATS (Usage access) – recently used apps

Used only if you turn on Recently used apps and grant Usage access in Android settings. A9 reads which apps were recently opened, to show them first. This data stays on the device.

POST_NOTIFICATIONS – Quick Launch notification

Used only if you turn on Quick Launch Panel, to show a notification with your most-used apps.

Calling a contact opens the system dialer with the number filled in; A9 does not request the permission to place calls itself.
